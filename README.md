# beyond-markdown
## D&amp;D Beyond Public and Owned content to LLM/AI Optimized Markdown
A local Node.js pipeline that extracts your legally owned D&D Beyond sourcebooks and compendium data, converting them into cleanly structured, AI-optimized Markdown.

Designed specifically to prepare TTRPG rulesets and adventures for Semantic Vector Databases, RAG pipelines, and LLM workspaces like Google's NotebookLM.

## 🚀 Features
* **Interactive CLI Hub:** A complete terminal menu to guide you through downloading and stitching.
* **Semantic Stitching:** Assembles hundreds of atomic chapter files into massive, coherent Master sourcebooks.
* **AI-Optimized Formatting:** Converts chaotic web-tables into flat text, reformats ability scores to save vertical space, and injects XML tags (<SOURCEBOOK>, <ENTRY type="MONSTER">) for perfect LLM semantic parsing.
* **Internal URN Routing:** Preserves official external URLs while injecting internal REF:SPELL metadata tags so AI models know exactly how to cross-reference your databases.
* **Ruleset Converter:** Programmatically updates older 2014 terminology, conditions, and weapon masteries to the 2024 SRD 5.2.1 standards.

### Prerequisites

- Node.js (v18+)
- A valid `CobaltSession` cookie from D&D Beyond.

## **🛠️ Installation**

1. Clone this repository to your local machine.  
2. Ensure you have [Node.js](https://nodejs.org/) installed.  
3. Install the required dependencies:
```
   npm install
```

## **🔑 Authentication Setup**

To access your owned books, you must provide your D\&D Beyond CobaltSession cookie.

1. Log in to [dndbeyond.com](https://www.dndbeyond.com)  
2. Press F12 to open Developer Tools.  
3. Navigate to **Application** \-\> **Storage** \-\> **Cookies**.  
4. Copy the value of the CobaltSession cookie.  
5. Run the master script (see below); it will prompt you for the cookie and securely save it to a local config.cjs file.

## **🕹️ Usage**

Everything is controlled through the interactive Master Hub. Simply run:

```
   npm run beyond-markdown
```

### **The Main Menu**

1. **Update Library Metadata:** Scans your D\&D Beyond account and creates a local map of every book you own. (Run this first\!)  
2. **Download & Stitch a Single Sourcebook:** Downloads a specific adventure or rulebook and compiles it into a single Master Markdown file.  
3. **Download & Stitch a Compendium:** Crawls the /spells, /monsters, or /magic-items databases and compiles them into a Master Database file.  
4. **Run Rules Converter:** Updates older 5e syntax to the newest ruleset formats.  
5. **BATCH CRAWL:** Automatically loops through your entire library, downloading and stitching every book you own while you step away.

## **📂 Output**

Generated Master files are saved in the sources/ directory. They are explicitly formatted as .md.txt files to bypass Google Drive's cloud-picker limitations, allowing you to easily import them directly into NotebookLM while preserving all Markdown syntax\!
